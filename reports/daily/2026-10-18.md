## 웹 밖의 공식 이용 경로

| 경로 | 기능·인증 | 공식 서버/문서 |
| --- | --- | --- |
| Scholar MCP | 논문 검색·본문 구간 검색·개별 논문 읽기·인용추적·Scholar Library 검색/읽기/저장. OAuth2.1 계정 로그인. 공식 페이지에 Codex 등 지원 클라이언트 탭 있음 | `https://api.liner.com/v1/mcp` |
| Search MCP | web/scholar 검색, quick answer/search/deep research agents. OAuth에서 과금 API키 선택 또는 API키 직접 인증. REST와 같은 요금·잔액 | `https://platform.liner.com/api/v1/mcp` |
| REST API | 프로그램에서 검색·답변·심층조사 호출. API키 필요. Search API는 메타데이터 검색이며 Scholar MCP 전체 기능과 동일하다고 보장하지 않음 | `https://liner.com/developers/docs/quick-start` |

- 공식 현행 가격/1,000회: Web Search $1, Scholar Search $0.30, Quick Answer $3, Search Agent $20, Deep Research $200. 개발자 API 잔액은 선불 방식. `GET /api/v1/credits/balance` 조회는 무료이며 사용량 단위는 USD의 백만분의 일이다.
- **공모전2,500크레딧을 API에 사용할 수 있다는 공식 설명은 확인되지 않았다.** 같은 Liner 계정이라는 이유로 잔액 공유·API 무료 사용을 단정하지 않는다. Scholar MCP의 해당 계정 요금·크레딧 차감도 공개 페이지에는 명확하지 않다.
- 실용적 판단: 논문 검색/읽기와 라이브러리 연동은 Scholar MCP가 직접 맞는 경로다. 연결 후 계정의 크레딧 적용 여부 확인이 필요하다. 웹의 모든 연구·작성 에이전트 기능이 Scholar MCP로 제공된다고 설명하지 않는다.
- 이번 작업은 공개 문서 확인뿐이다. MCP 설치·인증·API키 발급·잔액조회·유료 호출은 하지 않았다.
