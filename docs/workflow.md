# Radar 운영 규칙

1. 전 세계의 관련 기회를 제한 없이 찾는다. 연구·인턴십, 여름/겨울학교, 강좌, 학회, 워크숍, 세미나, 온라인 생중계와 녹화를 포함한다.
2. 공식 주최 기관 페이지를 열어 행사 날짜·신청 마감·학부생/한국 국적 자격·비용·재정지원·온라인 가능 여부를 확인한다. 모르는 값은 빈칸 또는 `미확인`으로 둔다.
3. `data/intake/`의 기존 링크와 `data/opportunities.csv`를 먼저 검색한다. 같은 기회는 새 행을 만들지 않고 기존 행의 `last_checked`, 상태, 다음 행동을 갱신한다.
4. `apply`, `watch`, `attend`, `committed`, `closed`, `review` 상태를 사용한다. 마감된 행을 삭제하지 않는다. 다음 회차가 있으면 `watch`로 두고 연도를 명확히 적는다.
5. 일정 충돌과 이동 부담은 `notes`에 기록한다. 기회를 임의로 제외하는 근거로 쓰지 않는다.
5.1. `data/evaluations.csv`에는 학술 적합성, 현지 경험 가치, 경쟁 강도, 준비 부담을 별도로 기록한다. 전공 밖 몰입형 프로그램은 경험 가치가 높으면 포함한다.
6. 매회 `reports/weekly/YYYY-MM-DD.md`에 신규, 상태 변경, 마감 임박, 재확인 필요, 이번 주 행동을 요약한다. 변경이 없어도 확인일과 확인 범위를 남긴다.
7. 사용자에게는 행동이 필요한 변경만 간결히 알린다. 보고서와 CSV를 저장하고 검증한 뒤 커밋·푸시한다. 푸시 실패 시 성공했다고 보고하지 않고 원인을 기록한다.

## CSV 필드

`id`는 한 기회를 여러 회차에 걸쳐 추적하는 고정 식별자입니다. 날짜는 ISO 형식 `YYYY-MM-DD`을 사용합니다. `deadline`은 신청·등록 마감이며, 시각/시간대가 중요하면 `notes`에도 기록합니다. `source_url`에는 공식 페이지를 넣습니다. `last_checked`는 해당 행의 사실관계를 마지막으로 확인한 날입니다.
