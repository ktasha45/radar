# Radar 적합성 판단 기준

이 파일에는 원격 저장소에 공유할 수 있는 일반적인 평가 원칙만 둔다. 개인의 학적·일정·장학금 상황은 기록하지 않는다. 로컬에 `docs/user-private.local.md`가 있으면 평가 전에 읽되, 그 파일은 Git에 추가하지 않는다.

## 탐색 범위와 우선순위

- 일반 연구 탐색의 여섯 축은 논리·기초/logic in CS, 복잡도·TCS, 수학적 ML·AI, 응용수학·과학계산, 수리생물·복잡계, 교육·진입 가치가 강한 인접 순수수학이다. 각 축에 동등한 탐색 권한을 두며 현재 프로젝트만으로 범위를 좁히지 않는다. 자세한 전문 출처는 [skill 탐색 지도](../skills/research-opportunity-radar/references/search-map.md)에 둔다.
- 학부생 대상이라는 표시가 없는 고급 행사도 현실적인 학습·교류 경로가 있으면 검토한다. 자격 미기재와 명시적 참가 금지를 구별한다. 연구자 중심 초청 프로그램과 학생용 학교를 같은 형식으로 추천하지 않는다.
- 수학과 컴퓨터과학의 접점뿐 아니라 각 분야의 독립적인 기회도 폭넓게 찾는다.
- 전공 밖이라도 사람들과 함께 새로운 것을 배우고 도시·현장을 경험할 수 있는 대면 프로그램을 포함한다. 한국 세미나, 세계 온라인 행사와 녹화도 계속 찾는다.
- 일정 가능성을 먼저 확인한다. 사람·도시·협업 경험의 가치를 크게 평가하고, 학술 주제의 적합성은 별도 항목으로 설명한다.
- 대면 기회는 총 여행비의 대부분을 지원하는 grant·급여·숙박 제공 여부를 실행 가능성의 핵심 조건으로 본다. 일부 자비 부담은 가능하지만, 지원이 없거나 금액이 미확인인 경우 우선순위를 낮추고 선지출·사후환급도 표시한다. 조사 대상에서 기회를 숨기지는 않는다.
- 지원 자격, 마감, 비용·장학, 기간·장소, 필요 서류, 준비 부담을 공식 출처로 확인한다.

## 판단 방법

1. 프로그램의 객관적 요건과 **확인된** 배경·일정을 대조한다. 미확인 사항은 적합/부적합으로 단정하지 않는다.
2. 선수지식과 세부 분야에 대한 관심은 구별한다. 세부 관심이 확인되지 않았다는 이유만으로 학술 적합성을 낮추지 않는다.
3. 학술 적합성과 현지 경험 가치를 별도로 평가한다. 일정·비용·이동·지원서 부담은 평가에 반영하되 탐색 단계에서 임의로 제외하지 않는다.
4. 과거 Radar의 점수보다 현재 확인된 정보와 사용자의 정정을 우선한다. 판단 근거와 남은 확인 사항을 함께 적는다.
5. 지적 적합성·교육 가치·학부생 접근성·지원/실비·일정/이동·교류/연구 가치·긴급성을 각각 본다. 미래 마감까지 14일 이하 URGENT, 3일 이하 VERY URGENT이며 원문 시간대와 한국 시각을 구분한다. 임박 공고에는 실제 확인한 요구 서류를 붙인다.
